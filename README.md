# VK-бот «Посвящение в Горную Академию» — v6

## Новая логика

- 6 команд.
- 6 станций.
- У каждой станции один общий 4-значный код для всех команд.
- У каждой команды свой маршрут из 6 станций.
- После правильного кода:
  1. станция отмечается пройденной;
  2. открывается очередной фрагмент одной общей клятвы;
  3. бот показывает задание на переход;
  4. бот показывает следующую станцию.
- После 6-го кода бот показывает всю клятву, задание на путь к финалу и место посвящения.
- После завершения маршрута появляется кнопка `📍 Место посвящения`.
- Кнопка `📜 Клятва` доступна всегда и показывает текущую открытую часть клятвы.
- HTML-теги вроде `<b>` в сообщениях не используются.

## Что настраивается в `/admin`

- включение/остановка мероприятия;
- название и 4-значный код каждой из 6 станций;
- 7 заданий на переход;
- одна общая клятва;
- место посвящения;
- название и 5-значный код каждой команды;
- регистрация/восстановление капитана;
- маршрут каждой команды;
- сброс прогресса команды или всех команд;
- статистика и таблица «кто где находится».

## Как делится клятва

Администратор вводит клятву целиком одним текстом. Бот автоматически делит её на 6 примерно равных фрагментов.
После 1-го кода открывается 1/6 текста, после 2-го — 2/6 и т.д. После 6-го кода показывается полный текст.

## Bothost

Entry point: `bot.py`

Persistent data: `/app/data`

Environment variables:

- `VK_TOKEN`
- `GROUP_ID`
- `ADMIN_LOGIN`
- `ADMIN_PASSWORD`
- `FLASK_SECRET`
- `PORT=3000`
- `DATA_DIR=/app/data`

Админка:

`https://YOUR-DOMAIN/admin`

Проверка:

`https://YOUR-DOMAIN/health`
