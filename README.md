# VK bot — Посвящение в Горную Академию v4

## Что изменено
- HTML-теги `<b>` больше не отправляются в VK.
- Для каждой команды отдельное фото клада.
- Нет раундов: капитан отправляет 4-значный код конкретной станции.
- Регистрация капитана — простой 5-значный код.
- В админке для каждой команды вводится готовое предложение.
- Система автоматически разбивает предложение на слова и пытается разбить слова на слоги.
- Для игры требуется ровно 5 слогов — по одному на каждую станцию.
- В админке задаются 5 кодов станций для каждой команды.
- В админке есть матрица прогресса: какая команда какие станции уже прошла.
- Есть автоматическая миграция старой SQLite-базы: отсутствующие поля добавляются при старте.

## Bothost
Entry point: `bot.py`
Port: `PORT` (например, 3000)
Persistent data: `/app/data`

Environment variables:
- `VK_TOKEN`
- `GROUP_ID`
- `ADMIN_LOGIN`
- `ADMIN_PASSWORD`
- `FLASK_SECRET`
- `PORT=3000`
- `DATA_DIR=/app/data`

Админка: `https://ВАШ-ДОМЕН/admin`
Проверка приложения: `https://ВАШ-ДОМЕН/health`

## Настройка в админке
1. Откройте `/admin` и войдите.
2. Для каждой команды задайте название и 5-значный код капитана.
3. Введите предложение.
4. Нажмите «Сохранить команду».
5. Система покажет автоматически получившиеся слова и 5 слогов.
6. Введите 5 кодов станций или нажмите «Сгенерировать 5 кодов станций».
7. Загрузите отдельную фотографию клада для команды.
8. После подготовки нажмите «Запустить выдачу слогов».

Важно: сохранение предложения сбрасывает прогресс этой команды, потому что меняются слова и слоги. Делайте настройку до начала мероприятия.

## Как работает капитан
- Первый вход: `🔑 Регистрация капитана` → 5-значный код команды.
- На станции: капитан отправляет 4-значный код станции.
- Бот определяет команду + станцию и выдаёт персональный слог.
- После 5 слогов команда собирает слова и затем предложение.
- После правильной фразы открывается фото клада именно этой команды.

## Восстановление
Администратор может сменить 5-значный код регистрации команды и дать его новому VK-аккаунту. Прогресс хранится в SQLite и не зависит от телефона капитана.
