# VK Bot — Посвящение в Горную Академию

## Новая механика

- Раундов больше нет.
- У каждой из 5 команд есть свой 5-значный код регистрации капитана.
- У каждой команды есть 5 индивидуальных цифровых кодов станций — всего 25 кодов.
- Организатор не переключает раунды и ничего не выдаёт в админке во время прохождения.
- На станции организатор сообщает капитану код этой станции.
- Капитан отправляет код боту.
- Бот определяет: команда + станция + персональный слог этой команды.
- Один и тот же код станции повторно не выдаёт слог.
- У каждой команды отдельная фотография клада.
- Фото клада можно загрузить и открыть отдельно для каждой команды.
- В сообщениях VK больше нет HTML-тегов `<b>` / `</b>`.
- При переходе капитана на другой телефон администратор может создать новый 5-значный код регистрации именно для этой команды. Прогресс не сбрасывается.

## Перед мероприятием

1. Откройте `game_config.py`.
2. Для каждой команды укажите название.
3. Укажите 5-значный `registration_code`.
4. Укажите 5 кодов `station_codes`.
5. Укажите персональные слоги, слова и финальную фразу.
6. Проверьте, что коды регистрации и коды станций не повторяются.
7. В админке загрузите 5 фотографий клада, по одной на команду.
8. Перед началом включите мероприятие.

## Bothost

Точка входа: `bot.py`
Порт: `PORT` (например 3000)
Данные: `/app/data`

Переменные:
- VK_TOKEN
- GROUP_ID
- ADMIN_LOGIN
- ADMIN_PASSWORD
- FLASK_SECRET
- PORT=3000
- DATA_DIR=/app/data

После публикации:
- `/admin` — админка
- `/health` — проверка, должна вернуть `status=ok`

## Регистрация капитана

Капитан нажимает `🔑 Регистрация капитана` и отправляет 5 цифр.

Пример:
`38142`

После регистрации бот сохраняет VK ID капитана за командой.

Если нужен другой телефон/VK:
- администратор нажимает `Новый 5-значный код` у этой команды;
- новый капитан отправляет этот код боту;
- команда и весь прогресс сохраняются.

## Коды станций

В конфигурации у каждой команды есть 5 кодов:

`station_codes = {1:'6148',2:'2751',3:'8036',4:'4927',5:'1573'}`

Например, если капитан Команды 1 отправляет `8036`, бот понимает, что это станция 3 именно Команды 1 и выдаёт слог из `syllables[3]`.
