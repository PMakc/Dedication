# VK Bot «Посвящение в Горную Академию»

## Админка
Откройте `https://ВАШ-DOMЕН/admin`. Корень `/` тоже ведёт на `/admin`.

## Переменные Bothost
`VK_TOKEN` — токен группы VK
`GROUP_ID` — ID группы VK
`ADMIN_LOGIN` — логин админки
`ADMIN_PASSWORD` — пароль админки
`FLASK_SECRET` — длинная случайная строка
`PORT` — например 3000
`DATA_DIR` — `/app/data`

## Капитан
В админке возле команды нажмите «Код подключения / восстановления».
Код можно выдать новому капитану или человеку, который сменил телефон. После ввода кода прогресс команды сохраняется, старый VK ID отвязывается.

## Важно
`game_config.py` содержит тестовые данные. Перед мероприятием замените слоги, слова и предложения на реальные для каждой команды.
