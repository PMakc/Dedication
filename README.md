# VK-квест «Посвящение в Горную Академию»

Полный первый прототип под Bothost.

## Главная механика

- 5 команд, у каждой свой маршрут.
- В каждом раунде капитан нажимает «Получить слог».
- Бот сам определяет текущую станцию команды и выдаёт **персональный** слог из `game_config.py`.
- Для каждой команды свои комбинации слогов → свои слова → своя финальная фраза.
- Сборка слов и предложения сделана кнопками VK.
- После правильной финальной фразы открывается фото клада.
- Админ-панель живёт в том же приложении: `https://ВАШ-ДОМЕН/admin`.
- Капитана можно перенести на другой VK-аккаунт временным кодом восстановления, не теряя прогресс.

## Важная схема раундов

Станции обозначены 1–5. У каждой команды есть `start`.
На каждом новом раунде команда автоматически сдвигается на следующую станцию по кругу.

Таким образом организатору не нужно вручную выдавать правильный слог — достаточно менять раунд в админке.

## Что изменить перед мероприятием

Откройте `game_config.py` и для каждой команды задайте:

- `name` — название;
- `start` — стартовую станцию;
- `syllables` — 5 персональных слогов, ключ = номер станции;
- `words` — правильная последовательность слогов для каждого слова;
- `sentence` — правильная последовательность готовых слов.

## Запуск локально

```bash
pip install -r requirements.txt
copy .env.example .env
python bot.py
```

Админка: `http://127.0.0.1:3000/admin`

## Bothost

Используйте `bot.py` как главный файл и задайте переменные окружения из `.env.example` в Bothost.
База и фото хранятся в `/app/data`.
Приложение слушает `0.0.0.0:$PORT`.

## Смена телефона капитана

Администратор нажимает «🔑 Код» напротив команды. Бот выдаёт одноразовый код примерно на 15 минут.
Капитан заходит с другого VK-аккаунта и отправляет код боту. Новый аккаунт получает команду, а прогресс сохраняется.
