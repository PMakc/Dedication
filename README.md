# VK Quest v5 — 6 команд / 6 станций

## Новая логика
- 6 команд.
- 6 станций.
- Для каждой станции один общий 4-значный код, одинаковый для всех команд.
- У каждой команды свой маршрут из 6 станций.
- После регистрации капитана бот показывает первую станцию и задание №1.
- После правильного кода станции бот отмечает станцию пройденной, выдаёт следующее задание на переход и показывает следующую станцию.
- После 6-го кода бот выдаёт задание №7 и направляет в финальную точку.
- В финале бот показывает, куда принести артефакты и текст клятвы.
- Никаких раундов и слогов/слов больше нет.

## Важный момент по 7 заданиям
Заданий 7: первое — перед первой станцией, затем ещё по одному после каждой из 6 станций. Так используются все 7 заданий.

## Админка
`https://YOUR-DOMAIN/admin`

В админке можно:
- включить/остановить приём кодов;
- задать 6 названий станций;
- задать 6 общих 4-значных кодов;
- задать 7 заданий на переход;
- задать финальную точку;
- задать клятву;
- для каждой из 6 команд задать название и 5-значный код капитана;
- задать маршрут каждой команды;
- получить временный код восстановления капитана;
- отвязать капитана;
- сбросить прогресс команды или всех команд;
- видеть, на какой станции сейчас находится каждая команда.

## Данные
Используется отдельная база `/app/data/quest_v5.db`, поэтому старая база предыдущей версии с другой схемой не мешает запуску новой версии.

## Переменные Bothost
`VK_TOKEN`, `GROUP_ID`, `ADMIN_LOGIN`, `ADMIN_PASSWORD`, `FLASK_SECRET`, `PORT`, `DATA_DIR=/app/data`.
